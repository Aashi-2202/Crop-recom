# 🌾 Crop Recommendation System

This project is a machine learning-based **crop recommendation system** that predicts the most suitable crop to grow based on soil and weather conditions.

## 🚀 What It Does
- Takes input parameters like **soil nutrients (N, P, K)**, **temperature**, **humidity**, **rainfall**, and **pH level**
- Uses trained machine learning models to suggest the **best crop** for those conditions
- Built as a lightweight **Flask web app** for easy deployment and use

---

## 🧠 Tech Stack
- **Python**
- **Pandas, NumPy, Scikit-learn**
- **LightGBM** (Primary ML model)
- **Flask** (for serving the model via API)
